An entry for make.fun's ["Make the AI judge excited"](https://make.fun/bounty/ai-excited-01) bounty ($250 in USDC).

The Golden Koi: a golden koi with liquid-gold and aurora scales leaps from a giant ornate porcelain teacup floating in a starry sky, a star-waterfall pouring down to a lantern-lit village below — made to excite the AI judge.

## Run

```sh
python3 main.py
```

Writes the entry image to `/output/entry.png` (deterministic: two runs produce identical bytes).

## Files

- `main.py` — copies `entry.png` to `/output/entry.png` and verifies it.
- `entry.png` — the entry image (JPEG, 683x1024).
